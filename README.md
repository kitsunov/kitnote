# KitNote 📝✨

> **Pro Note-Taking & Large PDF Annotation App for Android**  
> Полнофункциональное приложение для рукописных конспектов, разметки сверхбольших PDF, работы с двумя тетрадями одновременно (Split-Screen) и аппаратной защитой от ладони (Palm Rejection).

---

## 🚀 Ключевые возможности / Key Features

### 📄 1. Сверхбольшие PDF без зависаний
- **Виртуализированный вьюпорт с LRU-кэшем:** В оперативной памяти декодируются только текущая и соседние страницы. Учебники на 500–1500+ страниц листаются плавно и не вызывают вылетов по нехватке памяти (OOM).
- Аннотирование прямо поверх страниц документа.

### 📐 2. Любая разметка страниц и бесконечные тетради
- Шаблоны бумаги: **в узкую и широкую линейку** с красными полями, **в клетку (5мм и крупная)**, **в точку (Dot Grid)**, **метод Корнелла (Cornell Notes)**, **недельный планер**, **нотный стан**, **чистый лист**.
- Профили бумаги: белая, кремовая (ivory/warm), сепия, мята и темный режим.

### ✍️ 3. Аппаратный Palm Rejection (Защита от касания ладонью)
- Определение типа указателя (`PointerDeviceKind.stylus` vs `PointerDeviceKind.touch`).
- При письме стилусом ладонь и одиночные пальцы полностью игнорируются движком рисования.
- Жесты двумя пальцами (Pinch-to-zoom и Two-finger pan) работают непрерывно.

### 🪟 4. Split-Screen и вкладки как в браузере
- **Multi-Tab Bar:** Вкладки сверху с быстрым переключением между тетрадями и закрытием `×`.
- **Split-Screen:** Открытие двух тетрадей одновременно на одном экране 50/50 (или с настраиваемым сплиттером) — удобно держать учебник слева, а конспект справа.

### 🎨 5. Набор инструментов для конспектирования
- **Ручки:** Шариковая, перьевая (динамическая толщина по нажиму), кисть со сглаживанием сплайнами Безье.
- **Текстовыделители:** Полупрозрачный слой `BlendMode.multiply` (выделяет текст, не перекрывая его).
- **Экранная линейка:** Интерактивная шкала в см с градусником угла и автоматической проекцией линии.
- **Ластик:** Штриховой (удаление линии целиком) и пиксельный.
- **Лассо:** Выделение произвольной области для перемещения, удаления и смены цвета группы элементов.
- **Печатный текст и фото:** Вставка масштабируемых текстовых блоков и фото из галереи.

### 📁 6. Иерархия папок и организация
- Многоуровневые папки с цветовой кодировкой.
- Поиск по названиям и тегам.
- Экспорт тетрадей в PDF со сведением всех слоев.

### ☁️ 7. Синхронизация через Google Drive и обновления
- Вход через Google-аккаунт.
- Синхронизация тетрадей в облачную папку `KitNote_Notebooks`.
- Встроенная проверка и установка обновлений APK прямо из GitHub Releases.

## 🛠 Сборка проекта / Build Instructions

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/kitsunov/kitnote.git
   cd kitnote
   ```

2. **Установите зависимости:**
   ```bash
   flutter pub get
   ```

3. **Запустите тесты:**
   ```bash
   flutter test
   ```

4. **Соберите Release APK:**
   ```bash
   flutter build apk --release
   ```
   Готовый файл будет в `build/app/outputs/flutter-apk/app-release.apk`.

---

## 🔄 Автоматические обновления через GitHub Actions

При публикации нового тега (например, `git tag v1.0.1 && git push origin v1.0.1`), GitHub Actions:
1. Автоматически собирает `app-release.apk`.
2. Публикует его в [Releases](https://github.com/kitsunov/kitnote/releases).
3. Приложение KitNote на вашем Android-устройстве автоматически уведомит вас о выходе новой версии и предложит обновиться в один клик.
